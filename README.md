# Python Task Tracker

## Description
A simple task management application built with Python. It allows users to manage a list of tasks through an interactive command-line menu.

## Features
- Add new tasks
- View all saved tasks with task numbers
- Update existing tasks
- Delete tasks by task number
- Validate task numbers when updating or deleting
- Handle an empty task list
- Interactive menu with an option to exit

## Technologies
- Python 3
- Lists
- Loops
- Conditional statements (`if`, `elif`, `else`)
- User input and type conversion
- List methods such as `append()` and `pop()`
- List indexing and iteration

## How to Run
1. Install Python 3.
2. Download `tasktracker.py` from this repository.
3. Open a terminal in the folder containing the file.
4. Run the following command:

   `python tasktracker.py`
